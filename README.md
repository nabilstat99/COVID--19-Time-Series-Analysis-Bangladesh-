# COVID-19 Time Series Analysis: Bangladesh Case Study

## 📌 Overview
A Time Series Analysis of COVID-19 data for Bangladesh using Python and statistical forecasting methods.

## 🛠️ Tools
- Python (pandas, numpy, matplotlib, statsmodels)
- Google Colab
- Time Series Analysis
- Exponential Smoothing

## 📊 Dataset
- Source: Johns Hopkins University COVID-19 Dataset (GitHub)
- Country: Bangladesh

## 🔬 Methodology
1. Loaded global COVID-19 time series data from GitHub
2. Extracted Bangladesh-specific data
3. Calculated daily new cases
4. Applied 7-day moving average smoothing
5. Analyzed monthly trends
6. Built Exponential Smoothing model
7. Forecasted next 30 days

## 📈 Key Findings
- Identified major COVID-19 waves in Bangladesh
- Monthly patterns showed multiple peaks
- 7-day moving average smoothed weekly reporting variations
